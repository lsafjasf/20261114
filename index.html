FIELD NOTES / 操作提示

如何完成一段夜游

  1. 画出路径。选择「绘路径」，在画布上按下并拖动，听者会沿这条线穿过花园。
  2. 穿过六处感应。将路径拖过发光的感应圈；未触及的节点不会发声。
  3. 为节点调音。音高决定合成音的核心频率，延迟决定声音比脚步晚多少，衰减决定余响长度。
  4. 完整收听。播放六分钟。前段稀疏，环境声在行进中逐渐加密。

所有声音均由 Web Audio 实时合成，不读取任何音频文件。路径、节点与参数可保存为 JSON 后再次导入。
