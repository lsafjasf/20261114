# 地下泵站 · 双人协作稳态

本地双人协作游戏：两名玩家同屏操作一座地下泵站，把两个集水池稳定在安全门限内连续 **5 分钟**即胜利。

## 运行

```bash
python3 -m http.server 8123
# 浏览器打开 http://127.0.0.1:8123/index.html
```

纯静态页面，无需构建。浏览器要求支持 Canvas 2D 与 Web Audio。

## 玩法与协作设计

- **左位（进水阀操作员）**：只看阀位、来水压力、进水流量；键盘 `Q/A`、`W/S` 分别控制 A/B 池阀门。
- **右位（排水泵操作员）**：只看泵转速、出口压力、排水流量、停泵计时；键盘 `I/K`、`O/L` 分别控制 A/B 池泵。
- 双方都看不到对方的专属仪表，只能通过 **Canvas 剖面水位、共享总流量和共享报警频道** 沟通配合。
- 动作过猛（按住 `Shift` 快速操作）会在管路中激发 **水锤**，累积 100% 损伤即爆管失败；平缓操作则安全。
- 泵在低水位强行抽排水会 **气蚀** 损毁；任一台泵停止超过 15 秒 **平台淹没**；水位漫顶直接失败。
- 地下水持续渗入且有周期性涌水扰动，总排水流量还须保持在调度区间 `0.09–0.24 m³/s`。
- 点「自动驾驶演示」可观看两个自动玩家（`pilot.js` 中的阀位前馈 + 泵速 PI）如何完成协作稳态。

## 文件结构

- `sim.js`：UMD 物理仿真内核（水位连续方程、阀/泵流量、水锤、气蚀、淹水、稳态判定），浏览器与 Node 共用。
- `pilot.js`：两个独立自动玩家，模拟左右席位的有限信息决策。
- `audio.js`：纯 Web Audio 合成——泵机嗡鸣、水流噪声、水锤低频冲击、报警蜂鸣、气蚀嘶声、胜负旋律。
- `main.js`：固定步长游戏循环、键盘/按钮输入、Canvas 剖面渲染、不对称仪表面板、报警联动。
- `index.html` / `styles.css`：工业 SCADA 暗色界面。

## 验证

```bash
node test-steady.js     # 两个自动玩家真实跑完一次 5 分钟协作稳态（零水锤/零气蚀）
node test-fail.js       # 水锤爆管、停泵淹没、气蚀、漫顶、共享流量报警
node smoke-browser.js   # DOM 桩件加载完整前端栈，演示模式达成胜利
```

实测稳态结果：307 秒达成胜利，水位全程处于 0.46–0.61（门限 0.32–0.68），无水锤、无气蚀，总排水流量在调度区间内。
