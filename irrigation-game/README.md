# 山区灌溉渠 · 闸门调度

Canvas + WebAudio 的灌溉调度小游戏，纯前端、零依赖。

## 玩法

- 山溪经**进水闸**进入干渠，**分流闸**决定水去灌区还是蓄水池，**泄洪闸**防止蓄水池漫顶。
- 三块田串联灌溉：水位进入绿色目标带即完成（传感器采样确认），随后水自动流向下一田。
- **传感器每 2 秒才更新一次读数**，闸门动作有约 4 秒惯性——看着旧读数预判真实水位。
- 失败条件：任一田水位超过红色田埂线、蓄水池漫顶（下游溢出）、超时。
- 胜利条件：三块田全部完成灌溉，且蓄水池水位不低于红色最低蓄水线。
- 蓄水池有持续生态基流，山溪会随机爆发山洪，注意预警并开泄洪闸。

## 操作

- 滑块或键盘：`Q/A` 进水闸、`W/S` 分流闸、`E/D` 泄洪闸。
- 直接用浏览器打开 `index.html` 即可游玩（声音在点击「开始」后启用）。

## 文件

- `sim.js` — 纯逻辑仿真核心（闸门惯性、传感器延迟、山洪、农田/蓄水池水文）。
- `game.js` — Canvas 渲染、输入与音效。
- `test.js` — `node test.js`：仅用传感器读数的策略自动完成灌溉，30 个随机种子全部获胜。
- `smoke.js` — `node smoke.js`：DOM/Canvas 桩下运行渲染主循环 200 帧，验证无运行时错误。
