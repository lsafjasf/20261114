# 海岛净水站 12 分钟模拟

一个基于 Canvas 2D 和 Web Audio 的浏览器仿真。玩家操作一套预处理旁路、一台高压泵和两套反渗透膜组件，在海水浊度波动中维持供水和储水。

## 运行

```bash
python3 -m http.server 4173
```

然后打开 `http://127.0.0.1:4173/`。直接双击 `index.html` 也可运行，但推荐使用本地 HTTP 服务。

## 操作规则

- 预处理旁路：旁路越高，越多浊度负荷进入膜组件，堵塞更快。
- 高压泵压力：压力越高产水越多，但膜污染和寿命损耗更快。
- 自动反洗周期：周期越短越安全，但每次反洗暂停一套膜并消耗 54 L 储水。
- 立即反洗：高浊度事件后可手动触发，优先清洗污染更高的膜。
- 通过条件：完成 12 分钟，无膜堵塞或寿命耗尽，全程最低储水不低于 800 L。

Canvas 顶部绘制取水、预处理、高压泵、双 RO 膜和储水罐；下方绘制膜压、浊度和储水量趋势。开启泵音后，Web Audio 振荡器和水流噪声会随泵压升高而增强。

## 自动验证

```bash
npm test
```

测试覆盖：

- 稳定运行：低旁路、65 bar、150 秒反洗周期可完成 720 秒并守住 800 L 全程最低储水。
- 膜堵塞：100% 旁路、100 bar、关闭反洗会在 12 分钟内触发膜堵塞。
- 反洗机制：一次反洗消耗 54 L，并显著降低目标膜污染。
